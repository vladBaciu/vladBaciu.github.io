# Featured Projects - My Pinned Repositories

**Posted on:** October 14, 2026

Welcome! This is an overview of my most important and active projects. I focus on **Embedded Systems**, **Machine Learning**, and **Security** - particularly applied to wearable sensors and edge computing.

## 🌟 Featured Projects

### PPG & Biomedical Signals
My primary research area involves Photoplethysmography (PPG) for heart rate and SpO₂ monitoring:

- **[awesome-ppg](https://github.com/vladBaciu/awesome-ppg)** - Comprehensive collection of PPG resources, libraries, datasets, and papers
- **[PPG-EduKit](https://github.com/vladBaciu/PPG-EduKit)** - Educational platform for PPG signal evaluation and learning
- **[denoising-ppg-autoencoder](https://github.com/vladBaciu/denoising-ppg-autoencoder)** - PPG signal denoising using TensorFlow autoencoders with C inference engine
- **[pulseppg-distiller](https://github.com/vladBaciu/pulseppg-distiller)** - Pulse-PPG foundation model for wearable applications (UbiComp 2025)
- **[ML-PPG-EduKit](https://github.com/vladBaciu/ML-PPG-EduKit)** - Neural networks running on PsoC 6 microcontroller

### Machine Learning & Edge Devices
Bringing ML to resource-constrained embedded systems:

- **[MLino-Bench](https://github.com/vladBaciu/MLino-Bench)** - Comprehensive benchmarking tool for evaluating ML models on edge devices
- **[ecg-tcn](https://github.com/vladBaciu/ecg-tcn)** - Official code for ECG-TCN paper (AICAS2021)
- **[Segade](https://github.com/vladBaciu/Segade)** - Machine learning semantic segmentation for detecting artifacts in plethysmography signals

### Embedded Systems & Hardware
Low-level embedded development with microcontrollers and FPGAs:

- **[Arduino-Makefile](https://github.com/vladBaciu/Arduino-Makefile)** - Makefile workflow for Arduino sketching and flashing
- **[LPM01A-PowerShield-Control](https://github.com/vladBaciu/LPM01A-PowerShield-Control)** - Python library for STM32 power consumption measurement
- **[STM32H5-security-solution](https://github.com/vladBaciu/STM32H5-security-solution)** - Nonsecure application development with STM Secure Manager
- **[Sensorless-BLDC-controller](https://github.com/vladBaciu/Sensorless-BLDC-controller)** - Sensorless BLDC motor controller software
